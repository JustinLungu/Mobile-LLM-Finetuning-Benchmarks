# Android benchmark app

An Android app that tests how small language models run on a real phone, the counterpart of the [iOS app](../ios/). Everything runs on the phone; nothing is sent anywhere.

**Status: early.** The app builds and starts, but doesn't run models yet. A step-by-step guide will follow.

Android apps can be built on Linux, macOS or Windows with [Android Studio](https://developer.android.com/studio): open this `apps/android` folder in it.
